The Floating Display

One keystroke. Anywhere.

The floating panel uses a non-activating window, so it appears over your current app without yanking you away. Type, then dismiss — and the app you were in stays exactly where it was.

  • Works over full-screen apps on any Space.
  • Cursor lands in the editor instantly — start typing.
  • Dismisses cleanly and restores your previous app.
  • No Accessibility permission required.

MCP server

Your AI tools, writing into the same notes.json.

A local Model Context Protocol server for NoteFlow — Cursor, Claude Code, Claude Desktop, or any MCP client can list, search, create, and edit notes. The app watches the store and merges changes live. Nothing leaves your Mac.

Cursor Claude Code Claude Desktop Any MCP client

Eight tools

list_notes Title, tags, preview — pinned first
read_note Full plain-text body by id
search_notes Keyword match in title or body
note_stats Visible, pinned, tagged, trash counts
create_note New note with Markdown-like markup
write_note Replace or append content
update_note_title Rename without touching the body
formatting_help Markup cheat sheet for agents

Markup that lands as rich text

create_note / write_note accept Markdown-like content and encode it as NoteFlow RTF — same family, size, and colors the editor uses.

# / ## headings **bold** `code` & fenced blocks [link](url) {color:blue} / orange bullets & numbered lists :rocket: emoji shortcodes
  • Writes to ~/Library/Application Support/NoteFlow/notes.json via atomic temp + rename — the running app picks it up instantly.
  • Three-way merge keeps your keystrokes safe; API Key Manager pages and trash stay out of the tool surface.
  • Sensitive-looking notes are redacted in previews; each write keeps a rolling backup.

Only in NoteFlow

Your API keys, one menu-bar click away.

A page kind no other notes app has: paste your provider keys once, and copy them from the menu bar forever — without opening the app, without hunting through notes.

  • Structured provider cards — name, base URL, and as many labelled keys as you need.
  • Values render masked and never appear in search or previews — only labels match.
  • Pin keys, providers, or whole pages to the menu bar — copy key or base URL in one click.
  • Stored locally in your notes file — nothing leaves your Mac.
